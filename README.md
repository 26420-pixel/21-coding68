ใช้เรียน
ฝึกในวิชาเขียนโปรแกรม
ระบุปัญหา รับประทานอาหารตามความสะดวก โดยไม่ได้คำนึงถึงปริมาณพลังงานที่ได้รับต่อวัน
 Input (ข้อมูลนำเข้า)1.แคลอรี่ มื้อเช้า 2.แคลอรี่ มื้อกลางวัน 3.แคลอรี่ มื้อเย็น
 Process (กระบวนการทำงาน)1.	รับค่าตัวเลขจากผู้ใช้ 2.	คำนวณผลรวมแคลอรี่ทั้งหมด 3.	ตรวจสอบว่าเกิน 2,000 kcal หรือไม่
 Output (ผลลัพธ์)1.แสดงแคลอรี่แต่ละมื้อ	2.แสดงผลรวมทั้งหมด	3.แจ้งเตือน (ตัวเลขสีแดงเมื่อเกินกำหนด / สีเขียวเมื่อปกติ)
 ยากเเต่ทำได้ครับ พีชอบผังงานมากกว่าเพราะทำง่ายกว่า ยากที่สุด คือ ขั้นตอน Process เครื่องมือที่ใช้ได้เเก่ Python ชื่อผู้พัฒนา ศุภณัฐ แจ่มศรี ครูผู้สอนครูนฤล สุนทอง
